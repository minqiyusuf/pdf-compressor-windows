# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a focused branch.
3. Keep document processing local by default.
4. Do not introduce telemetry or PDF uploads without an explicit design discussion.
5. Keep Ghostscript version/hash changes explicit and reviewable.
6. Submit a pull request explaining the behavior change and how it was tested.

By contributing, you agree that your contribution is provided under the repository's AGPL-3.0-or-later license.
